POLÍTICA DE PRIVACIDADE Última atualização: Agosto de 2026 A Credcore Financiamentos respeita a privacidade dos seus clientes e está comprometida com a proteção dos dados pessoais tratados em suas atividades, em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD). QUEM SOMOS A Credcore Financiamentos é uma empresa especializada em soluções de crédito consignado, refinanciamento, portabilidade e demais produtos financeiros. Responsável: Bruno Ferreira da Silva CNPJ: 54.989.191/0001-95 E-mail para contato: [atendimento@credcorefinanciamentos.com.br](mailto:atendimento@credcorefinanciamentos.com.br) DADOS COLETADOS Podemos coletar informações como: • Nome completo • CPF • Telefone • E-mail • Matrícula funcional • Contracheque • Informações necessárias para análise de crédito • Dados fornecidos voluntariamente pelo cliente UTILIZAÇÃO DOS DADOS Os dados coletados são utilizados para: • Simulação de crédito • Análise de elegibilidade • Contato comercial • Envio de propostas • Formalização de contratos • Atendimento ao cliente • Cumprimento de obrigações legais e regulatórias COMPARTILHAMENTO DE DADOS A Credcore poderá compartilhar informações com instituições financeiras, bancos, correspondentes bancários e parceiros comerciais quando necessário para análise, contratação, refinanciamento, portabilidade ou demais operações de crédito solicitadas pelo cliente. SEGURANÇA DAS INFORMAÇÕES Adotamos medidas técnicas e administrativas para proteger os dados pessoais contra acessos não autorizados, perda, alteração ou divulgação indevida. DIREITOS DO TITULAR O titular dos dados poderá solicitar: • Confirmação do tratamento dos dados • Acesso aos dados armazenados • Correção de informações incorretas • Atualização cadastral • Exclusão dos dados quando aplicável • Informações sobre compartilhamento de dados CONTATO Solicitações relacionadas à privacidade podem ser enviadas para: [atendimento@credcorefinanciamentos.com.br](mailto:atendimento@credcorefinanciamentos.com.br) ALTERAÇÕES DESTA POLÍTICA Esta Política de Privacidade poderá ser alterada a qualquer momento para adequação legal, regulatória ou operacional.
